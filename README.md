# Monster Hunter Campaign Tracker UI

A web app to track Monster Hunter campaigns. Built with React + TypeScript + Vite.

---

## 🚀 Getting Started

```bash
npm install
npm run dev
```

---

## 🧱 Tech Stack

- React
- TypeScript
- Vite

---

## 📁 Project Structure

- src/ – Main app source
- public/ – Static assets

---

## 📦 Scripts

| Command           | Description          |
| ----------------- | -------------------- |
| `npm start`       | Start dev server     |
| `npm run build`   | Build for production |
| `npm run preview` | Preview built app    |
